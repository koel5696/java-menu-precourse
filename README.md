# 메뉴 추천

### 개요

- 간단하게 점심 메뉴를 추천해주는 서비스를 구현한다.

## 📌 구현 기능

### 1. 입출력 기능

- 점심 메뉴 추천을 시작하는 안내문을 출력하는 기능을 구현한다.
- 코치의 이름을 입력 받는다.
    - [예외] 코치의 이름은 2~4글자로 이뤄진 한글이름이다.
    - [예외] 코치의 인원 수는 2~5명까지이다.
    - [예외] 코치의 이름은 유일하다.
    - [예외] 구분은 쉼표(,)로 이뤄진다.
- 각 코치 별로 먹지 못하는 음식을 입력받는다.
    - [예외] 못 먹는 음식은 0~2개까지이다.
    - [예외] 못 먹는 음식은 쉼표(,)로 구분한다.
    - [예외] 메뉴는 유일하다.
- 못 먹는 음식 리스트는 다음과 같다.

### 2. 핵심 메뉴 추천 기능

- 메뉴를 추천하는 과정 월,화,수,목,금 각 요일 별로 카테고리를 무작위로 선정한다.
    - [규칙] 각 카테고리의 랜덤 숫자를 부여한다.
    - [규칙] 부여된 숫자를 바탕으로 해당 요일에 추천할 카테고리를 적용한다.
    - [규칙] 각 카테고리의 중복은 최대 2회까지만 가능하다.
- 각 코치별로 못 먹는 메뉴에 대한 리스트를 생성한다.
- 메뉴 추천을 구현한다.
    - [규칙] 선정된 카테고리의 음식 리스트를 랜덤 셔플하여 첫번째 메뉴를 추천한다.
    - [규칙] 만약 추천된 메뉴가 먹지 못하는 메뉴이면 다시 셔플한다.
    - [규칙] 만약 추천된 메뉴가 중복 메뉴이면 다시 셔플한다.
    - [규칙] 코치에게 추천할 메뉴를 정할 때 이미 추천한 메뉴, 먹지 못하는 메뉴도 포함된 리스트를 전달해야 한다.

### 3. 기타 기능

- 메뉴 추천을 완료하면 프로그램이 종료된다.
- 사용자가 잘못된 값을 입력할 경우`IllegalArgumentException`를 발생시키고, "[ERROR]"로 시작하는 에러 메시지를 출력 후 그 부분부터 입력을 다시 받는다.
    - `Exception`이 아닌`IllegalArgumentException`,`IllegalStateException`등과 같은 명확한 유형을 처리한다.

## ⚠️ 구현 제약 사항 (Checklist)

- 프로그램 종료 시`System.exit()`를 호출하지 않는다.
- indent(인덴트, 들여쓰기) depth를 3이 넘지 않도록 구현한다.
- 3항 연산자를 쓰지 않는다.
- 함수(또는 메서드)의 길이가 15라인을 넘어가지 않도록 구현한다.
- else 예약어와 switch/case는 사용하지 않는다.
- 카테고리의 메뉴 목록을`List<String>`형태로 준비한다.
